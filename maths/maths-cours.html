Généralités sur les fonctions
Analyse · 60 min

Points clés du résumé

  • Définition : Une fonction f associe à chaque nombre x de son domaine de définition un unique nombre f(x).
  • Domaine : Ensemble des réels x pour lesquels f(x) existe.
  • Parité : f est paire si f(-x) = f(x) et impaire si f(-x) = -f(x).
f(x) = 2x + 1 \text{ est croissante sur } \mathbb{R}

Points clés du résumé

(x^n)' = n x^{n-1} \quad ; \quad \left(\frac{1}{x}\right)' = -\frac{1}{x^2}
