Fonctions de base

Dérivée de \(x^n\)\((x^n)' = n x^{n-1}\)
Dérivée de \(\sqrt{x}\)\((\sqrt{x})' = \frac{1}{2\sqrt{x}}\)
Dérivée de \(\frac{1}{x}\)\((\frac{1}{x})' = -\frac{1}{x^2}\)

Exponentielle & Logarithme

Dérivée de \(e^x\)\((e^x)' = e^x\)
Dérivée de \(e^{u(x)}\)\((e^u)' = u' e^u\)
Dérivée de \(\ln(x)\)\((\ln x)' = \frac{1}{x}\)
Dérivée de \(\ln(u)\)\((\ln u)' = \frac{u'}{u}\)

Fonctions trigonométriques

Dérivée de \(\sin(x)\)\((\sin x)' = \cos x\)
Dérivée de \(\cos(x)\)\((\cos x)' = -\sin x\)
Dérivée de \(\tan(x)\)\((\tan x)' = 1 + \tan^2 x = \frac{1}{\cos^2 x}\)

Opérations sur les dérivées

Somme\((u+v)' = u' + v'\)
Produit\((u \cdot v)' = u'v + uv'\)
Quotient\((\frac{u}{v})' = \frac{u'v - uv'}{v^2}\)

Primitives usuelles

\(x^n\)\(\int x^n dx = \frac{x^{n+1}}{n+1} + C\)
\(\frac{1}{x}\)\(\int \frac{1}{x} dx = \ln|x| + C\)
\(e^x\)\(\int e^x dx = e^x + C\)
\(\cos(x)\)\(\int \cos x dx = \sin x + C\)
\(\sin(x)\)\(\int \sin x dx = -\cos x + C\)

Formes composées

\(u' e^u\)\(\int u' e^u dx = e^u + C\)
\(\frac{u'}{u}\)\(\int \frac{u'}{u} dx = \ln|u| + C\)
\(u' \cos u\)\(\int u' \cos u dx = \sin u + C\)
\(u' \sin u\)\(\int u' \sin u dx = -\cos u + C\)

Identités fondamentales

Relation de Pythagore\(\sin^2 x + \cos^2 x = 1\)
Tangente\(\tan x = \frac{\sin x}{\cos x}\)
Relation avec \(\tan\)\(1 + \tan^2 x = \frac{1}{\cos^2 x}\)

Formules d'addition

\(\cos(a+b)\)\(\cos(a+b) = \cos a \cos b - \sin a \sin b\)
\(\cos(a-b)\)\(\cos(a-b) = \cos a \cos b + \sin a \sin b\)
\(\sin(a+b)\)\(\sin(a+b) = \sin a \cos b + \cos a \sin b\)
\(\sin(a-b)\)\(\sin(a-b) = \sin a \cos b - \cos a \sin b\)

Formules de duplication

\(\cos(2x)\)\(\cos(2x) = \cos^2 x - \sin^2 x = 2\cos^2 x - 1\)
\(\sin(2x)\)\(\sin(2x) = 2 \sin x \cos x\)

Propriétés des logarithmes

Produit\(\ln(a \cdot b) = \ln a + \ln b\)
Quotient\(\ln(\frac{a}{b}) = \ln a - \ln b\)
Puissance\(\ln(a^n) = n \ln a\)
Racine\(\ln(\sqrt{a}) = \frac{1}{2} \ln a\)

Propriétés des exponentielles

Produit\(e^{a+b} = e^a \cdot e^b\)
Quotient\(e^{a-b} = \frac{e^a}{e^b}\)
Puissance\((e^a)^n = e^{an}\)
Inverse\(e^{-a} = \frac{1}{e^a}\)

Liens Log / Exp

Réciprocité\(e^{\ln x} = x \quad (x > 0)\)
Réciprocité\(\ln(e^x) = x\)
Équation\(e^x = y \iff x = \ln y \quad (y > 0)\)
