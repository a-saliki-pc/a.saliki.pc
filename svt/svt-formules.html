Lois de Mendel

Monohybridisme (F1 x F1) \(F_2\) : 3/4 [Dominant] ; 1/4 [Récessif]
Dihybridisme (F1 x F1) \(F_2\) : 9/16 ; 3/16 ; 3/16 ; 1/16

Calculs de probabilités

Probabilité d'un phénotype \(P = \frac{\text{Nombre de cas favorables}}{\text{Nombre de cas possibles}}\)
Test du \(\chi^2\) (Khi-deux) \(\chi^2 = \sum \frac{(O - T)^2}{T}\)

Synthèse des protéines

Transcription (ADN → ARNm) A → U ; T → A ; C → G ; G → C
Code génétique (ARNm → Acides aminés) 1 codon (3 nucléotides) = 1 acide aminé

Datation absolue

Loi de décroissance radioactive \(N = N_0 \cdot e^{-\lambda t}\)
Âge de l'échantillon \(t = \frac{1}{\lambda} \ln\left(\frac{N_0}{N}\right)\)

Stratigraphie

Principes fondamentaux Superposition, continuité, recoupement
Failles et plis Faille normale (extension) / inverse (compression)

Cycles biogéochimiques

Cycle du carbone Photosynthèse, respiration, décomposition
Cycle de l'azote Fixation, nitrification, dénitrification
